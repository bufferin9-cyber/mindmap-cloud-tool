# マインドマップ クラウド化ツール

FreeMindの `.mm` 資産を活かしつつ、ブラウザだけでマインドマップを作成・編集できる軽量なWebアプリです。ビルド不要、依存ライブラリはCDNから読み込みます。

## 使い方

このページ(`index.html`)をブラウザで開くだけで使えます。

- 「.mm読み込み」でFreeMindの`.mm`ファイルを読み込み(画面へのドラッグ&ドロップも可)
- ノードのダブルクリックで編集、右クリックで各種メニュー
- ノードへの画像挿入(ボタン、またはコピーした画像をCtrl+Vで貼り付け)
- 「テキスト書き出し(AI用)」でマインドマップの構造をテキストとして書き出し、生成AIへの相談に利用可能
- 上部タブで「業務フロー」(Mermaid.js記法のフローチャート)、「関係図」(人物・組織のつながりを自動描画)にも切り替え可能

保存はブラウザのlocalStorage内で完結します(このページを開いた端末・ブラウザ内のみで有効)。

## 技術構成

- [MindElixir](https://github.com/SSShooter/mind-elixir-core) v5 — マインドマップ描画
- [Mermaid.js](https://mermaid.js.org/) v10 — 業務フロー図
- [vis-network](https://visjs.github.io/vis-network/) v9 — 関係図
- いずれもCDN読み込み、ビルド・サーバー不要の静的サイト
